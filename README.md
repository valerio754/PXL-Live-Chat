# 🚀 PXL-Live: Sistema de Chat Colaborativo

Proyecto desarrollado para la materia de **Sistemas Colaborativos** por el grupo **PIXEL**. Este sistema permite la comunicación bidireccional en tiempo real entre múltiples empleados de una empresa utilizando el protocolo WebSocket.

##  Características Principales
- **Comunicación en Tiempo Real:** Uso de WebSockets para evitar el polling.
- **Persistencia:** Los mensajes se guardan en una base de datos local (SQLite).
- **Identificación Temporal:** Asignación automática de alias para usuarios.
- **Interfaz SPA:** Aplicación web de una sola página con modo oscuro.

##  Stack Tecnológico
- **Lenguaje:** Python 3.x
- **Framework Backend:** FastAPI & Uvicorn
- **Frontend:** HTML5, CSS3 (Flexbox) y JavaScript Vanilla
- **Base de Datos:** SQLite
